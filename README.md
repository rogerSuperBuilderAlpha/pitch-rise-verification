# Pitch Rise Verification

This repository contains verification scripts for Pitch Rise verification codes.

## Usage

### Python Script

```bash
python verify.py PITCH-1I5E-AJ1S-JJY6
```

Or run interactively:
```bash
python verify.py
```

## Verification Code Format

Verification codes should follow the format:
- `PITCH-XXXX-XXXX-XXXX`
- Where XXXX is 4 alphanumeric characters (A-Z, 0-9)

## Example

```bash
python verify.py PITCH-1I5E-AJ1S-JJY6
```
